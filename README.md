# Equal Earth

An interactive world map in a single HTML file.

- Switch between the **Equal Earth** projection (Šavrič, Patterson & Jenny, 2018) and **Mercator**, with an animated morph between them
- Drag left or right (mouse or touch) to rotate the central meridian; press Reset to return to 0°
- **Snapshot** saves the current view as a 2800 px PNG with a caption
- Country shapes and names from Natural Earth 1:110m, embedded in the page
- The view is encoded in the URL, e.g. `#proj=mercator&lon=100`
- Vanilla JavaScript on a canvas, no external dependencies, works offline

Live: https://pisut-cmkl.github.io/equal-earth/
