# Equal Earth

An interactive Equal Earth world map in a single HTML file. Drag left or right (mouse or touch) to rotate the central meridian; press Reset to return to 0°.

- Equal Earth projection (Šavrič, Patterson & Jenny, 2018), implemented directly in vanilla JavaScript on a canvas
- Country shapes and names from Natural Earth 1:110m, embedded in the page
- No external dependencies; works offline

Live: https://pisut-cmkl.github.io/equal-earth/
